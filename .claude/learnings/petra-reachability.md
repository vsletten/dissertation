# Petra mechanism reachability

- A local proof from the zero-step neighborhood is not a reachability proof.
  Hydrolysis elsewhere can create the distance-two witness that unlocks a center;
  apply witness paths through the compiled live engine and record the event
  prefix.
- Clearing every aliased state to one generic oxygen vacancy can create invalid
  kind/state combinations. Adversarial fixtures must replace a state with a
  valid state from the same kind and then refresh live event tables.
- For fixed-boundary kaolinite cations, a useful topology NO-GO invariant is the
  cation ladder index plus its available nonfrozen intact adjacent bridges.
  Forward hydrolysis transfers one unit from bridge to ladder; reverse
  condensation restores it. Adsorption-created oxygen occupancy cannot add a
  net bridge-removal unit without a compensating condensation decrement.
- Importance-sampled transition failure must restore RNG state as well as model
  state, time, step count, and likelihood weight; branch and selector resolution
  may consume draws before failing.
